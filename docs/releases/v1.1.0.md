# Forklift v1.1.0

Forklift v1.1.0 is the first release under the engine's permanent name. It
keeps the proven classical evaluator and search from v1.0.0, while replacing
the desktop experience and expanding the project's reproducible strength
research tooling.

## Highlights

- A complete minimalist SFML desktop redesign with aligned board coordinates,
  tactile controls, smooth piece movement, original move sounds, and a native
  Windows icon.
- Manual and adaptive per-move timing, including Eco, Balanced, Performance,
  and Performance+ profiles, user-set maximum time, suggestions, overrun
  display, and corrected live resource telemetry.
- A resumable Stockfish ladder with a live dashboard, W/D/L and current-game
  boards, explicit seed control, permanent CSV evidence, and reproducible
  calibration charts.
- Forklift branding across the desktop app, UCI identity, web interface,
  packages, README, and Wiki.
- A verified Windows desktop archive that contains `Forklift.exe`, assets, the
  UCI/tools executables, SFML DLLs, and OpenAL. Release automation now tests the
  complete package before publication.

## Strength status

The latest completed reproducible estimate remains the approximately 2321.5
crossing in the 1,200-game Stockfish 18 limited-strength ladder at `10+0.1`.
The earlier v1-versus-v0.4.0 gate scored `299-18-83` over 400 games. These are
pool- and time-control-specific engine measurements, not official human or
Chess.com ratings.

The longer 2,400-game `30+0.3` calibration is deliberately not claimed here:
it began from the exact pre-release engine commit and was still running when
v1.1.0 was prepared. Its full evidence will be published separately after all
four rungs finish.

## NNUE status

NNUE tooling remains experimental and no network is enabled by default. The
five-million-position v1 network and its hybrid variants did not beat the
classical evaluator in controlled matches, so v1.1.0 makes no unearned neural
strength claim.

## Windows download

Download `Forklift-1.1.0-Windows-AMD64-GUI.zip`, extract it, and run
`bin/Forklift.exe`. No separate SFML installation is required.
